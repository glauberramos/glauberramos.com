About

When I was 17, when I really started to write code
I definitely wanted to build products of my own
It was almost impossible because the dream was so big
That I didn’t see any chance because

I was living in Porto Alegre, in the south of Brazil; was working as a consultant
And all I really wanted to do was build products
And not only build them, but make them grow by themselves

At that time, in 2015, we had a retrospective meeting, and the tool was so old
So I would stay up at night after work, writing code with Firebase
I built the first version in like one weekend
And I said, “Wait a second, I know the shareable link
Why don’t I use the shareable link, which is the growth of the future?”
So I gave every board a URL, no signup, no login,
Which then was shared with whole teams around the world
But I didn’t realize how much the impact would be

In 2018 I quit my job, packed a backpack, and traveled the world
Then in 2020 the whole world went remote
And the users tripled in one week; half a million people
Running retrospectives on a tool I built in one weekend, alone

My name is Glauber Ramos
